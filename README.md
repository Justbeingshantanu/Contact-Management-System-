## Contact Management System 📇

Built a simple Python-based Contact Management System as one of my beginner projects while learning Python. The idea was to create a small application that makes storing and managing contacts easier through a simple, menu-driven interface.

It allows users to add new contacts, view saved details, search for specific people, update information, and delete contacts whenever needed.

Through this project, I got hands-on experience with Python dictionaries, loops, conditional statements, and functions. It also helped me understand how CRUD operations work and how different Python concepts come together to solve a practical problem.

**Tech Used:** Python

**Key Features:**
- Add and save new contacts.
- View all stored contacts.
- Search contacts by name.
- Update existing contact details.
- Delete unwanted contacts.
- Handle duplicate phone numbers.

This project is a small step in my Python learning journey, focused on improving my problem-solving skills and building a stronger programming foundation.
